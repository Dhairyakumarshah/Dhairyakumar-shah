Palantir AIP — NHS A&E Operational Intelligence Workflow

An end-to-end AI workflow built on Palantir AIP using real NHS England A&E open data (OGL v3.0) — 2,372 records across 200+ trusts for the 2024–25 period, designed and delivered independently from scratch. I engineered a Foundry batch pipeline and modelled an AE_Attendance ontology exposing trust-level performance metrics — breach rates, 12-hour waits, total attendances — then configured AIP Analyst so the data could be queried in natural language instead of manual SQL and ad-hoc reporting. An operational action type flags high-risk trusts for escalation, closing the loop from ingestion through to decision support.

  • East Cheshire NHS Trust identified as the highest breach-rate trust in March 2025 (49.96%)
  • NHS England Midlands surfaced as the region with the most 12-hour waits across 2024–25 (123,264 cases)

Agentic Medical Information Chatbot (RAG)

A chatbot that answers health-information questions over a curated knowledge base using a Retrieval-Augmented Generation pipeline, grounding responses in retrieved text to reduce hallucination. Built with an open-source Llama model orchestrated through LangChain, with document ingestion, chunking and embedding into a vector database, and retrieval tuned for relevance. Ships with a disclaimer making clear it provides information, not medical advice.
